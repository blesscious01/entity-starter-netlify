Entity starter for Minecraft Bedrock add-ons

Latest checks components strictly: one bad value and the entity won't load.

Pick a vanilla mob to fill every section from the real game files, then change anything. Blank leaves everything empty.

Behaviors
Movement

Weight is how likely a mode is picked next. Seconds is how long it lasts.

Every mode is built from components copied from vanilla mobs (parrot, bee, allay, chicken, bogged), so the game already knows them. Range and speed change the vanilla numbers. Ground modes glide down for 3 seconds first, unless a condition forces them.

Spawning

Bedrock has no clock filter, so time is set by light level.

Dimensions (none checked = any)
Biomes in the chosen dimensions (none checked = anywhere in them)
Relationships
Hunts (when hostile)
Runs away from
Taming, tempting, breeding
Combat and survival
Drops and extras
Events: when this happens, do that

Used by "Every few seconds". Temporary effects last 10 seconds.

Tags and traits

Added when it spawns, so commands and scripts can find it with @e[tag=...].

Biome variants

Each variant appears in its own biome with its own color, size and trait. Let the mob spawn in those biomes too. Colors need a generated model.

Glow and particles

Glow works on generated textures, or on Blockbench textures with half-transparent glow pixels.

Component library (everything vanilla)

Add any vanilla component, attribute, trigger or behavior goal by name, then edit its values as JSON, following Mojang's docs for that name. Attach it to the base entity or to one movement mode. Behaviors take a "priority" value.

Mojang entity docs and bedrock.dev reference list every field and default.

Paste the result into any component's "filters" field.

Import a vanilla mob

Paste a vanilla entity file, or pick one. Copy them from Mojang's bedrock-samples repository. Its components, groups and events become the base, and your settings are added on top.

Older vanilla files may need the 1.21 target version above.

Raw JSON (advanced)

Model and texture

Generated models match the hitbox and get move and idle animations for the movement type. With the mood property on, the enraged mood gets its own texture.

Blockbench: File, Open Model, pick the saved .geo.json, then import the .png. Keep the bone names, edit, save both, then pick "Use my Blockbench files".
